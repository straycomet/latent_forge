# Experimentation Log

## 2026-05-24 — Remote Open WebUI over Tailscale

### Experiment

Remote Open WebUI access over airplane Wi-Fi and Tailscale.

### Observation

Latency was extremely high, approximately 800 ms–2 s, but the interface remained usable.

### Lesson

Inference can remain local while the UI remains remotely accessible.

### Next step

Improve handling for high-latency remote sessions.
